# ResQFlow baseline (general disaster dispatch)

The original **general** ResQFlow demo is preserved in:

- [`index.html`](../index.html) — geometry ranking, GAPD, 8-check closed-loop on a generic simulated plant
- [`graph.html`](../graph.html) — NetworkX digital twin explorer
- [`experiments/`](../experiments/) — offline benchmarks for the generic model

**ResQFlow-Flood** specializes the same architecture for urban flood evacuation. See [`flood.html`](../flood.html), [`flood-graph.html`](../flood-graph.html), [`ARCHITECTURE-FLOOD.md`](../ARCHITECTURE-FLOOD.md), and [`scenarios/`](../scenarios/).

Flood features (simulator, routing, Flood-GAPD, 8-check verify, UI, tests, benchmarks) are implemented alongside this baseline.
